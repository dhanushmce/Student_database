# Student Database (JDBC)

A Java application demonstrating CRUD operations (Create, Read, Update, Delete) 
on a student records database using JDBC.

## Tech Stack
Java, JDBC, MySQL

## Files
- Createcon.java — Establishes database connection
- insert.java — Add new student records
- select.java — Retrieve student records
- update.java — Modify existing student records
- delete.java — Remove student records

## What I Learned
- Connecting Java applications to a MySQL database via JDBC
- Writing parameterized queries for basic CRUD operations
